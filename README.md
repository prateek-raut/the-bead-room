# 🌸 The Bead Room by Pallas

A modern e-commerce web platform and workshop booking system crafted for **The Bead Room by Pallas**.

## 🌟 Brand Highlights
- **Handcrafted Jewellery 🌸**: Bracelets, Necklaces, Rings & Phone Charms — **Pan-India Delivery**
- **Curated Art Workshops 🎨**: Creative sessions in Nagpur where attendees make and take home handcrafted pieces — **Hosted at 107, Amba Appts., Surendranagar, Nagpur**
- **Contact Email**: `sarakamdar26@gmail.com`

---

## 🛠️ Features
- **Storefront**: Glassmorphic luxury UI, category filters, instant search, product quick view modal, cart slide drawer, promo code engine, and pan-India checkout.
- **Direct Inquiry Dispatch**: Customer inquiries and custom orders are sent directly to `sarakamdar26@gmail.com`.
- **Protected Admin Panel (`/admin.html`)**: Password-protected management dashboard (`sarakamdar26@gmail.com` / `Pallas@123`) for product uploads, drag-and-drop media, inquiry inbox, and order tracking.

---

## 🚀 How to Run Locally

```bash
# Option 1: Double-click start-server.bat
# Option 2: Run via Node.js
npm install
npm start

# Option 3: Run via PowerShell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

Access the Storefront at `http://localhost:3000/` and Admin Portal at `http://localhost:3000/admin.html`.
